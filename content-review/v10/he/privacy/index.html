איזה מידע נאסף

האתר הוא אתר סטטי. אפשר לגלוש בו בלי להירשם ובלי למסור לנו שום פרט אישי.

המקום היחיד שבו האתר אוסף מידע אישי הוא טופס יצירת הקשר ותיאום ההדגמה בעמוד הקליניקות (וגם בגרסה האנגלית שלו). כשממלאים את הטופס, אנחנו מקבלים את מה שהוזן בו:

  • שם
  • כתובת אימייל
  • מספר טלפון
  • שם הקליניקה או הארגון
  • תפקיד
  • עיר
  • הערכה של מספר המטופלים עם שברים בחודש
  • ההודעה שכתבתם

אנא אל תכללו בטופס פרטים של מטופלים או מידע רפואי אחר.

למה אנחנו משתמשים במידע

אנחנו משתמשים בפרטים מהטופס רק כדי לחזור אליכם בעניין הפנייה, ולתאם הדגמה או פיילוט אם ביקשתם. אנחנו לא מוכרים את המידע ולא משתמשים בו לפרסום.

שירותים חיצוניים

כמה שירותים של צד שלישי מעורבים בהפעלת האתר:

  • FormSubmit ‏(formsubmit.co). הטופס נשלח דרך FormSubmit, שירות חיצוני להעברת טפסים, שמעביר את הפרטים במייל ל-office@gero3d.com. השירות מעבד את הפנייה כדי למסור אותה לנו.
  • GitHub Pages. האתר מאוחסן ב-GitHub Pages. כמו רוב שירותי האחסון, GitHub עשויה לשמור נתונים טכניים על הגישה לאתר, למשל כתובות IP.
  • Google Fonts. הגופנים באתר נטענים מ-Google Fonts, ולכן כתובת ה-IP שלכם נשלחת לגוגל כשהדפדפן טוען אותם.

כל אחד מהשירותים האלה מטפל במידע לפי תנאי הפרטיות שלו. הסרטונים באתר מאוחסנים אצלנו ולא בפלטפורמת וידאו חיצונית.

עוגיות, אנליטיקה ופרסום

האתר עצמו לא שומר עוגיות (cookies). כרגע אין באתר כלי אנליטיקה ואין מעקב פרסומי. אם נחליט להוסיף כלי אנליטיקה, נעדכן את המדיניות הזו לפני כן.

כמה זמן המידע נשמר

אנחנו שומרים את הפרטים מהטופס רק כל עוד הם נחוצים כדי לטפל בפנייה שלכם, ובהדגמה או בפיילוט שביקשתם.
